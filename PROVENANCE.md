# M15 preview provenance

This preview uses original local Astro components, semantic HTML, and local CSS. It uses Astro, TypeScript, Tailwind CSS 4 through the official Vite plugin path, and Playwright only as declared development tooling. No third-party block, template, component code, imagery, font file, runtime dependency, telemetry, or external network request has been copied or added.

The structure follows the locally documented selected quiet centered-product shell (`docs/R05-COMMON-SHELL-SELECTION-2026-08-30.md`) and maps the frozen M10 token values from `docs/tokens/lunowa-m10.tokens.json` into CSS custom properties and Tailwind theme tokens in `src/styles/global.css`.

This is an M15 browser preview, not production implementation and not ACP G7 acceptance.
